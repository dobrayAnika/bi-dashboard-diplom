# BI-Dashboard — low-code BI-инструмент

Дипломный проект (ВКР): веб-приложение для построения BI-дашбордов бизнес-метрик в low-code формате. Пользователь без навыков программирования загружает свои данные, настраивает нужные метрики через drag-and-drop интерфейс и получает готовый интерактивный дашборд с графиками и AI-интерпретацией.

## Функциональность

- Расчёт и визуализация ключевых бизнес-метрик e-commerce: **GMV, AOV, ARPC, RGR**, количество уникальных клиентов, прирост новых клиентов, выручка по месяцам, количество заказов
- Пользователь загружает файл с данными в формате **CSV или Excel**, после чего настраивает отображаемые метрики через drag-and-drop интерфейс — сопоставляет столбцы своих данных с нужными полями метрик
- Интеграция с **GigaChat API** — генерирует текстовую интерпретацию графиков и метрик на естественном языке, помогая пользователю без аналитического бэкграунда понять, что показывают данные
- Интерактивные графики на **Plotly**, дашборд собирается динамически на основе выбранных пользователем метрик

## Стек технологий

| Слой | Технологии |
|---|---|
| Backend | Python, Flask |
| База данных | PostgreSQL, SQLAlchemy (ORM) |
| Обработка данных | Pandas |
| Визуализация | Plotly |
| AI | GigaChat API |
| Frontend | HTML, CSS, JavaScript |

## Архитектура проекта

```
bi-dashboard-diplom/
├── app.py                 # основное Flask-приложение
├── templates/              # HTML-шаблоны интерфейса
│   ├── index.html
│   └── bi_tool.html
├── mapping_config.json     # конфигурация маппинга столбцов данных на метрики
├── metadata.json           # метаданные загруженных датасетов (структура, типы столбцов)
├── performance_test.py     # замер времени загрузки дашборда и времени отклика GigaChat API
└── requirements.txt        # зависимости проекта
```

## Моя роль

Самостоятельная разработка проекта от идеи до реализации в рамках выпускной квалификационной работы: проектирование архитектуры и схемы базы данных, реализация backend-логики на Flask, расчёт бизнес-метрик, интеграция визуализации через Plotly и AI-функциональности через GigaChat API.

## Установка и запуск

```bash
git clone https://github.com/dobrayAnika/bi-dashboard-diplom.git
cd bi-dashboard-diplom
pip install -r requirements.txt
```

Создать файл `.env` в корне проекта со своими переменными окружения (пример структуры):

```
DATABASE_URL=postgresql://user:password@localhost:5432/dbname
GIGACHAT_API_KEY=your_key_here
```

Запуск:

```bash
python app.py
```

## Результаты

- Функциональное тестирование пройдено полностью: 12 из 12 сценариев (ручное чёрное тестирование)
- Время загрузки дашборда — менее 1 секунды
- Время отклика GigaChat API — около 3 секунд, не зависит от объёма данных (на сервер передаются только агрегированные значения метрик)
- Решение сравнивалось с Power BI, Tableau и Metabase — сравнение легло в основу обоснования разработки собственного инструмента
- Проект защищён в рамках ВКР
